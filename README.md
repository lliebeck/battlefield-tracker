## General

This is a hobby project that was born out of a passion for the Battlefield series. With the help of the open REST API https://api.gametools.network, I have created a website that allows you to find your current game lobby and display the data of your fellow players. This allows you to quickly check whether a teammate or opponent is an obvious cheater, or if your favourite server has enough players. The application is currently publicly hosted on Netlify, so check it out at https://mygamelobby.de.

## Getting Started

First, install the needed packages:

```bash
npm i
```

Then run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
